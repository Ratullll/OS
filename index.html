💡 CPU Scheduling Fundamentals & Formulas

Essential operating system scheduling concepts, definitions, and mathematical relationships used in OS kernels.

Completion Time CT
CT = Clock at finish

The exact clock timestamp at which a process finishes executing its entire burst workload.

Turnaround Time TAT
TAT = CT − AT

Total elapsed time between process arrival in the ready queue and full completion.

Waiting Time WT
WT = TAT − BT

Total time a process spends waiting in the ready queue without CPU access.

Response Time RT
RT = First CPU Run − AT

Time elapsed between initial arrival and the very first CPU cycle allocated to the process.

1. First-Come First-Served (FCFS)

Non-Preemptive

Allocates CPU in strict order of process arrival. Simple to implement using a FIFO queue. Vulnerable to the Convoy Effect, where short jobs wait behind a massive CPU burst process, resulting in elevated average waiting times.

• Overhead: Minimal • Starvation: Impossible

2. Shortest Job First (SJF / SRTF)

Non-Preemptive & Preemptive

Selects the process with the shortest burst time. SRTF (Preemptive SJF) is mathematically proven to generate the minimal average waiting time for any given set of processes, but long jobs may suffer from starvation.

• WT: Provably Optimal • Risk: Long-job Starvation

3. Priority Scheduling

Rank-Based Scheduling

Executes processes based on assigned priority rankings. In preemptive mode, an arriving higher-priority process immediately interrupts the running job. Real OS kernels employ Aging to gradually raise priority for waiting jobs.

• Priority Rule: Configurable • Solution: Aging technique

4. Round Robin (RR)

Time-Sliced (Preemptive)

Designed for interactive time-sharing systems. Each ready process receives a fixed time quantum q. If unfinished after q, it is preempted to the tail of the ready queue. Balances fairness and response latency.

• Fairness: Maximum • Responsiveness: Immediate
